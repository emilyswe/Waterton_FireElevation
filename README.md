The Bioacoustic Unit collected data from 2018-2021 in the park. 
Each year of data collection was stored as a different project in WildTrax.
In addition, Parks Canada also collected data (before and after the fire).
For 2021 and 2022, Parks Canada transcribed their data on WildTrax, but they used an abundance cap of 3 individuals.
PC has currently contracted Bioacoustic Pathways to re-transcribe their 2021 and 2022 data without the abundance cap.
For 2008-2019, Parks Canada has uploaded their recordings to WildTrax, but they have not completed uploading tags (there are zero tags for these recordings).
This is because their 2007-2019 data was transcribed using time to first detection for the 10 min recording, but abundance tags were done in 3 bins (0-3m20s,3m21s-6m40s, 6m41s-10m). 
This means standardizing survey effort with the historical PC data requires extracting tags for 3 minutes, but we only have the abundance for 3min20sec segments without knowing the time individuals were detected.
PC's only record of the tags for the 2007-2019 data is in the "PC_WLNP_EI Monitoring_2007to2009.csv" file.
So for example, in the #detected_0-3m20s column we know the abundance was three, if we want to use only individuals detected in the first 3 mins, we don't know if the 20s we shave off would have contained the tags.
WLNP staff are going to create tags from their historical data for upload to the recordings on WildTrax (completion date TBD).
